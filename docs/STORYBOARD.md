# 吃灰 · 水彩横屏 MV 分镜

> 这是制作时的原始分镜。文中的 `MV素材/截图/` 对应本仓库的 `assets/shots/`，`MV素材/音频/` 对应 `assets/`，`painted_mv/` 就是本仓库根目录。

**规格**：1920×1080 横屏（16:9），24 帧，全长 3:38.41（`音频/吃灰.mp3` + `音频/吃灰.srt`）。
**节拍**：88 BPM，一拍 0.682 秒，一小节 2.727 秒。大部分歌词一句正好一小节，镜头按小节切；Rap 段按半小节切。首拍偏移还没测，开工时用 `beat_grid.py` 对齐。
**做法**：主人公、小鸡和场景用 p5.brush 水彩代码绘制（复制 `古风/白囍/painted_mv/` 模板改，把画布从白囍的 1080×1920 改回 1920×1080，横屏也是 painted-animation 模板的默认画幅）；真实截图放进手绘的手机、显示器或卡片框里，和水彩画面混排。**这条视频画面里可以出现文字**：截图原文、代码生成的界面、音效大字都可以用。

## 一句话

一个白天给别人打工的程序员，半夜在机友群里抢便宜 VPS，买了二十台「小鸡」全在吃灰；他说不清买来干嘛，只知道深夜连上 SSH 那一秒，自己是 root。最后他发现，自己也是城市机房里一台没人记得 IP 的小鸡，而凌晨两点没睡的，还有九十九加个同类。

## 贯穿全片的意象

- **小鸡**：每台 VPS 画成一只圆滚滚的黄色小鸡，头顶一盏小绿灯（在线），胸前挂城市牌（LA / 东京 / 香港 / 法兰克福）。它们住在机柜格子里。
- **灰**：「吃灰」就是灰尘一层层落在小鸡身上。灰尘在显示器光里飘，是每场夜戏的底色。第一遍副歌开头，落灰聚成片名「吃灰」。
- **绿灯**：探针上的「在线」就是小鸡头顶的绿灯。结尾满城窗户亮起，每扇窗里一盏绿灯，接上「一个都不掉队」。
- **凌晨 2:00**：开头和最后一遍副歌都停在凌晨两点，前后呼应。

## 颜色走向

深夜藏蓝 + 屏幕青光（主歌一）→ 暖橙粉（副歌，下单时陶醉）→ 卧室暗调 + 终端绿（主歌二）→ 高饱和快切（Rap）→ 白天办公室灰黄，再回到深夜 SSH 绿（Bridge）→ 冷紫城市 + 机房蓝（主歌三）→ 暖金，满城窗户亮起（最后一遍副歌）。

## 画面布局

- 歌词条在画面下方 y≈940–1010，居中；主要动作和截图放在它上方（y≈60–900）。最底下 60 像素留给播放器进度条。
- **基本构图是左右两栏**：一边是阿灰（或小鸡），一边是截图。人物在左时截图放右，下一镜反过来，避免连续几镜都同一侧。
- 宽截图（如 A06、A11、A17、A23、A29、A32）直接放在显示器或浏览器框里，可以占到画面宽度的 70%～80%；超宽的横条（A06、A17、A18）在框里水平平移。
- 竖截图（如 A09、A16、A26）放在手机框里，立在画面一侧，高度不超过 800 像素。
- 小截图（A02、A19、A25、A33）只做弹出卡片，宽度不超过原图的 1.5 倍，免得糊。
- 和声（括号里的歌词）用小一号的字，放在主歌词右上方。

## 实际制作记录

- **代码项目**：`R&B/吃灰/painted_mv/`（从 `古风/白囍/painted_mv/` 复制，画布改成 1920×1080）。截图直接从 `MV素材/截图/` 载入，没有另外复制。
  - 场景文件按段落分：`v1_verse.js`（前奏 + 主歌一）、`v1_pre.js`（预副歌一）、`c1_chorus.js`（副歌一）、`v2_verse.js`、`c2_chorus.js`（预副歌二 + 副歌二）、`r_rap.js`、`b_bridge.js`、`v3_verse.js`、`f_final.js`（最后副歌 + 尾声）。
  - 角色在 `ch_cast.js`，道具在 `ch_props.js`、`ch_props2.js`；歌词条在 `src/karaoke.js`，是从 SRT 合并重复句后手工整理的。
- **节拍**：`config.js` 里写的是 87.6 BPM、首拍 0.248 秒。这是按前 45 秒测的，后半段测出来不太稳定，节拍只用在小动作上，镜头切点以 SRT 为准。
- **和声时间**：SRT 里有几处和声时间不可靠，以下几句是按唱法推的：「就是亏」「就没了」「一顿饭钱~」「不算没人陪~」「我是 root~」「没人记得~」「一个都不掉队~」。
- **和分镜不一样的地方**：
  - 预副歌一的「再观望一下就没了」改成先显示 4 Available，刷新后变 0，再盖「售罄」章。
  - 预副歌二的同一句改成盖「又没了」章。
  - 副歌二「下单那一刻很陶醉」用了手指慢动作按 Order Now。
- **出片命令**（在 `painted_mv/` 下运行）：
  - 渲染帧：`node render.mjs --frames --workers=3`
  - 合成视频：用 ffmpeg 把 `out/frames` 和 `assets/song.wav`（`吃灰_new2.wav`，与原 mp3 是同一版、完全对齐）合成到 `../MV/`，音频编成 AAC 320k / 48kHz。
- **封面**：`MV/吃灰_封面_16x9.jpg`（1920×1080）和 `MV/吃灰_封面_4x3.jpg`（1440×1080）。
  - 底图没有从成片截（成片每帧都有歌词条），而是 `src/scenes/cover.js` 单独画的：左下阿灰举着手机一脸陶醉，右上一柜落灰的小鸡，最后一格新来的那只亮着。
  - 4:3 用三列机柜，从 1920 宽里裁中间的 1440。
  - 标题用华文中宋、米白、拉开字距、只加柔影，放在左上角，避开脸、手机和机柜；右下角留给时长角标。
  - 重出命令：在 `painted_mv/` 下运行 `python make_cover.py`。
